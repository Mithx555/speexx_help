# Speexx Helper

Chrome Extension สำหรับช่วยจัดการแบบฝึกหัดบน Speexx Portal พร้อมการตั้งค่าเวลา การทบทวน และรายงาน Debug เพื่อช่วยตรวจปัญหา

> Repository นี้ตั้งใจเผยแพร่เป็น **Private** ระหว่างพัฒนา เจ้าของโปรเจกต์สามารถเปลี่ยนเป็น Public ได้เองภายหลังจากหน้า Settings ของ GitHub

## ความสามารถ

- เริ่มทำแบบฝึกหัดทั้งชุด หรือเฉพาะข้อปัจจุบัน
- โหมดจับเวลา กำหนดเวลาต่อข้อ ช่วงทบทวน และแจ้งเตือนก่อนหมดเวลา
- โหมดทำอัตโนมัติต่อเนื่อง พร้อมทบทวนระหว่างข้อ
- แผงสรุปเซสชัน: จำนวนข้อ เวลา และจำนวนครั้งทบทวน
- ปุ่มส่งออก Debug เพื่อคัดลอกรายงานข้อผิดพลาดและ DOM ที่เกี่ยวข้อง
- รองรับหลายรูปแบบแบบฝึกหัด รวมถึง Drag & Drop และ Scrambled sentence
- ซ่อน/แสดงรายละเอียดการทำงาน และย่อแผงควบคุมได้

## การติดตั้งสำหรับผู้ใช้

1. ดาวน์โหลดหรือ Clone repository นี้ลงเครื่อง
2. เปิด Chrome แล้วไปที่ `chrome://extensions/`
3. เปิด **Developer mode** ที่มุมขวาบน
4. เลือก **Load unpacked**
5. เลือกโฟลเดอร์ `extension` จาก repository นี้
6. เปิด `https://portal.speexx.com/` แล้วกดไอคอน Speexx Helper เพื่อตั้งค่า

หลังแก้ไขโค้ด ให้กดปุ่ม Reload ของส่วนขยายในหน้า `chrome://extensions/` และรีเฟรชหน้า Speexx

## วิธีรายงานปัญหา

เมื่อพบปัญหา ให้กด `⧉ ส่งออก Debug` ในแผง Speexx Helper แล้ววางรายงานที่คัดลอกไว้ใน Issue หรือส่งให้ผู้ดูแลโครงการ รายงานประกอบด้วยสถานะเซสชัน คำเตือน ข้อผิดพลาด และข้อมูล DOM ที่จำเป็นต่อการวิเคราะห์

## โครงสร้างโปรเจกต์

```text
extension/
├── manifest.json       # การตั้งค่า Chrome Extension
├── content.js          # ระบบทำแบบฝึกหัด แผงควบคุม และ Debug
├── content.css         # รูปแบบของแผงลอยบนหน้า Speexx
├── popup.html          # หน้าตั้งค่าของส่วนขยาย
├── popup.js            # การบันทึกและรีเซ็ตการตั้งค่า
├── popup.css           # รูปแบบหน้าตั้งค่า
├── background.js       # Background service worker
└── icons/              # ไอคอนส่วนขยาย
```

ใน `content.js` และไฟล์หน้า Settings มีคอมเมนต์ภาษาไทยกำกับจุดสำคัญ เพื่อให้แก้ไขและต่อยอดได้ง่าย

## ข้อควรทราบ

- ใช้งานเฉพาะบัญชีและเนื้อหาที่คุณมีสิทธิ์เข้าถึง
- โครงสร้างหน้า Speexx อาจเปลี่ยนแปลงได้ หากพบปัญหาให้ส่ง Debug report เพื่อช่วยปรับปรุงการรองรับ
