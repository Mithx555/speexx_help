# Speexx Helper

Speexx Helper เป็น Chrome Extension ที่ช่วยให้จัดการแบบฝึกหัดบน Speexx Portal ได้สะดวกขึ้น มีตัวเลือกเรื่องเวลา การทบทวน สรุปเซสชัน และเครื่องมือ Debug สำหรับเวลาที่บางอย่างทำงานไม่ตรงตามคาด

> ตอนนี้โปรเจกต์ยังเป็น **Private** ระหว่างพัฒนา หากพร้อมเผยแพร่ เจ้าของ repository สามารถเปลี่ยนเป็น Public ได้จากหน้า Settings ของ GitHub

## ทำอะไรได้บ้าง

- เริ่มทำทั้งชุด หรือเลือกทำเฉพาะข้อที่กำลังเปิดอยู่
- ตั้งเวลาต่อข้อ เวลาทบทวน และการแจ้งเตือนก่อนหมดเวลา
- ใช้โหมดทำต่อเนื่อง โดยพักทบทวนระหว่างข้อได้
- ดูสรุปเซสชัน เช่น ทำไปกี่ข้อ ใช้เวลากี่นาที และทบทวนกี่ครั้ง
- ส่งออก Debug Report เพื่อเก็บรายละเอียดเวลาพบปัญหา
- ใช้ Debug Toolkit เพื่อตรวจโครงสร้างหน้า คัดลอก HTML แบบปิดบังค่าในช่องกรอก และล้างบันทึกเดิม
- รองรับแบบฝึกหัดหลายรูปแบบ รวมถึง Drag & Drop และ Scrambled sentence
- ย่อแผงควบคุม ซ่อนรายละเอียดการทำงาน ล็อกตำแหน่ง หรือรีเซ็ตกลับมุมขวาบนได้
- ตรวจดู Release ใหม่จาก GitHub และเปิด Issue พร้อมข้อมูล Debug ได้จากในแผง

## ติดตั้งใช้งาน

1. ดาวน์โหลดหรือ Clone repository นี้ลงเครื่อง
2. เปิด Chrome ไปที่ `chrome://extensions/`
3. เปิด **Developer mode** ที่มุมขวาบน
4. กด **Load unpacked**
5. เลือกโฟลเดอร์ `extension` ใน repository นี้
6. เปิด `https://portal.speexx.com/` แล้วกดไอคอน Speexx Helper เพื่อตั้งค่า

หากแก้โค้ดแล้ว ให้กด Reload ที่การ์ดส่วนขยายใน `chrome://extensions/` และรีเฟรชหน้า Speexx อีกครั้ง

## เจอปัญหาต้องทำอย่างไร

กด `⧉ ส่งออก Debug` บนแผง Speexx Helper เพื่อคัดลอกรายงาน จากนั้นวางไว้ใน GitHub Issue หรือส่งให้ผู้ดูแลโปรเจกต์ได้เลย รายงานจะมีสถานะของเซสชัน คำเตือน ข้อผิดพลาด และข้อมูลหน้าเว็บที่ช่วยให้ตามปัญหาได้เร็วขึ้น

สามารถกด `New issue` บน GitHub เพื่อใช้แบบฟอร์มรายงานปัญหา และควรอ่าน [Privacy Policy](PRIVACY.md) ก่อนแชร์ Debug Report ทุกครั้ง

## โครงสร้างโปรเจกต์

```text
extension/
├── manifest.json       # ข้อมูลและสิทธิ์ของ Chrome Extension
├── content.js          # การทำงานบนหน้า Speexx, แผงควบคุม และ Debug
├── content.css         # หน้าตาแผงลอยบนหน้า Speexx
├── popup.html          # หน้าตั้งค่าของส่วนขยาย
├── popup.js            # บันทึกและรีเซ็ตการตั้งค่า
├── popup.css           # หน้าตาของหน้าตั้งค่า
├── background.js       # งานเบื้องหลังของส่วนขยาย
└── icons/              # ไอคอนส่วนขยาย
```

ใน `content.js` และไฟล์หน้าตั้งค่ามีคอมเมนต์ภาษาไทยไว้ตรงจุดสำคัญ เพื่อให้กลับมาแก้หรือเพิ่มฟีเจอร์ต่อได้ง่าย

## หมายเหตุ

หน้า Speexx อาจมีการปรับโครงสร้างในอนาคต หากส่วนขยายทำงานผิดปกติ ช่วยส่ง Debug Report มาด้วย จะช่วยให้แก้ปัญหาได้ตรงจุดมากขึ้น
